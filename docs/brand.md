# Brand assets

The notedrop mark is a folded terminal note dropping into an inbox. Use the
supplied PNGs at their original aspect ratios, with the surrounding padding
intact. Keep the project name and descriptive text available outside images
for accessibility.

| Asset | Dimensions | Use |
| --- | --- | --- |
| [Icon](assets/notedrop-icon.png) | 1254 × 1254 | Project avatar |
| [Banner](assets/notedrop-banner.png) | 2172 × 724 | README header |
| [Social card](assets/notedrop-social.png) | 1774 × 887 | Link previews |

## Palette

| Color | Role |
| --- | --- |
| `#07130F` | Deep forest background |
| `#57F2A0` | Phosphor green mark and cursor |
| `#D7FFE8` | Pale mint lettering and highlights |

The artwork uses stepped pixel edges and monospace lettering. These colors
are palette references; the PNGs include nearby shades for glow and texture.
The assets were AI-generated and are raster images, not vector sources.
